判定の根拠を読む

j-0002 を訂正する。判定は変えない。訂正するのは根拠の残し方である。

j-0002 は隣接記事の改訂IDを記録していなかった。そのため、そこに書いた
「社会関係 961字」「バーチャルYouTuber 62,343字」「有名人崇拝症候群 2,759字」は
どの版を測ったものか特定できず、第三者が再現できない。

このプロジェクトは「隣接記事は必ず revision ID を記録する」を規則にしている。
j-0002 はその規則を作る前の記録で、規則に適合していない。

今日の版で測り直すと、3つとも公開値と一致しない:

社会関係 961字 → 848字 (revid 109609383)
バーチャルYouTuber 62,343字 → 54,023字 (revid 110862940)
有名人崇拝症候群 2,759字 → 1,740字 (revid 110672598)

差が記事の書き換えによるものか、当時の数え方が今の算出規則と違ったのかは、
もとの版を特定できないので判別できない。どちらであるかを確かめる手段が無い。

判定の実体は今日の版でも確認できた。 「社会関係」(revid 109609383) には
== パラソーシャル関係 == の節が現存し、「現実に対面したことがない相手に対して、
一方的に親近感や友情を感じる関係性」という定義がある。単一の隣接記事が概念を
定義しているため、実質包含の規則を満たす。他2記事にも言及が現存する。

3記事の本文を run-20260922T184629Z として証拠バンドルに収めた。以後この判定は
./run.sh verify でネットワーク無しに検算できる。

この訂正が示すこと: 改訂IDを記録しないと、自分の書いた数字を自分で検算できなくなる。
検算できない数字を根拠に使わない、というこのプロジェクトの主張を、看板にしている事例
そのものが破っていた。数字が合わなかったことより、合わない理由を特定できないことが問題である。
